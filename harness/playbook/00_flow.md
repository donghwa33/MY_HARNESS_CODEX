## 시간 규칙
- 14:00 하드스톱. 서술형 준비 대기(최대 10분, 재시도 시 다시 10분) + 30분을 반드시 남긴다.
- 168분에 무조건 제출을 시작한다. 남은 작업은 HANDOFF 의 열린 질문으로 남긴다.

## 병렬 원칙
- Codex 가 오래 걸리는 작업(코드 작성·실행)을 하는 동안 사람은 DM 인터뷰, 문서 검토, EXPLAIN 정리를 한다.
- 터미널을 용도별로 나눈다: T1 메인 codex / T2 레드팀 codex / T3 서버 / T4 수동 명령.
- Codex 가 "승인 대기" 상태면 기다려도 진행되지 않는다. 다른 일을 하다가도 주기적으로 확인한다.
