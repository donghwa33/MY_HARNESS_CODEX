## 라운드 1 — 정의와 기대
```
<호칭>님, 자료 확인했습니다. 정확히 정리하고 시작하려고 몇 가지만 여쭤볼게요.
1. "<지표>"는 <정의 후보> 기준이 맞을까요? <중복·재측정 등 애매한 처리>는 어느 기준으로 보시나요?
2. 변화는 <대상> 전체에서 나타나나요, 일부에서만 크게 나타나나요?
3. 지금까지 직접 확인하신 것과 배제하신 원인이 있으면 알려주세요.
4. 결과를 누가 어떤 형태(보고서 장수, 화면·도구 필요 여부, 반복 사용 여부)로 쓰시나요?
```

## 라운드 2 — 변경점 4M + 측정 (인벤토리의 열 이름·기간을 넣어 구체화)
```
원인 후보를 빠짐없이 잡으려고 변경점을 여쭤볼게요. <기간> 기준입니다.
1. 설비: <공정·설비군> 에서 PM, 부품 교체(공급사 변경 포함), 레시피 변경, 신규 설비 투입이 있었나요?
2. 자재: <언급된 자재> 외에 다른 자재 Lot 이나 공급사 변경이 있었나요?
3. 측정: <측정 관련 열> 프로그램·장비·판정 기준 변경이 있었나요?
4. 다른 제품·라인도 같은 시기에 변했나요?
```

## 라운드 3 — 제약과 성공 기준
```
마지막으로 조치 쪽 여쭤볼게요.
1. 원인 설비·자재가 나오면 바로 세우거나 바꿀 수 있나요? 그때 생산 영향은요?
2. 원인 확인용 실험(Split, 모니터 Lot)은 가능한가요?
3. 이미 진행 중인 조치(클레임, 변경 요청 등)가 있나요?
4. "이 정도면 됐다"고 할 기준이 있다면요?
```
