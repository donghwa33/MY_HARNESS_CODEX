# 결정 로그

## 목적
결과에 영향을 주는 선택을 추적 가능하게 남겨 코드·커밋·보고서와 연결하고, 후속 서술형 질문에 답할 재료를 만든다.

## 절차
1. work/DECISIONS.md 에 다음 번호로 항목을 추가한다.
2. 필수 칸: 결정 / 대안(2개 이상) / 근거(파일·표·진술 출처) / 영향(다른 대안을 택하면 결과가 어느 방향으로 얼마나 바뀌는가) / 확인 방법(테스트 이름 또는 검증 스크립트) / 커밋.
3. 근거가 업무 담당자 진술이면 INTERVIEW.md 번호를 적는다.
4. 결정을 구현한 함수 docstring 첫 줄에 D-번호를 쓴다.
5. 커밋 메시지에 D-번호를 쓰고, 커밋 후 해시를 항목에 적는다.
6. 결정이 바뀌면 기존 항목을 지우지 않고 "D-00x 변경 → D-00y" 로 새 항목을 만든다.

## 하지 말 것
- 사람이 결정하지 않은 선택을 결정으로 기록하지 않는다. 제안은 "제안" 으로 표시한다.
- 영향 칸을 "없음" 으로 비우지 않는다. 작다면 얼마나 작은지 숫자로 쓴다 (sensitivity 결과 인용).
