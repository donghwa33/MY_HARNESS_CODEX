# Handoff

## 목적
compact 없이 맥락을 파일로 넘겨, 새 세션이나 다른 사람이 3분 안에 이어받게 한다.

## 절차
1. work/STATE.md, AGREEMENT.md, DECISIONS.md, FINDINGS.md, REVIEW.md(있으면)를 다시 읽는다. 기억에 의존하지 않는다.
2. harness/templates/HANDOFF.md 형식으로 work/HANDOFF.md 를 쓴다. 이전 handoff 가 있으면 덮어쓰지 않고 "HANDOFF #N" 섹션을 맨 위에 추가한다.
3. README 필수 조건·성공 기준별 상태를 충족/부분/미충족 + 근거 파일로 쓴다.
4. "지켜야 할 결정" 에는 결과에 영향이 큰 것만 최대 4개, 어겼을 때 생기는 일과 함께 쓴다.
5. "하지 말 것" 에는 이 시점에 새 세션이 저지르기 쉬운 실수를 쓴다 (이미 기각된 방법 재시도 등).
6. 실행 중인 서버가 있으면 포트, 실행 명령, 실행 중인 터미널 이름을 적는다.
7. 재현 명령이 지금 동작하는지 실행해 확인하고 결과를 한 줄로 적는다.
8. work/STATE.md 를 갱신하고 `[HANDOFF-N] 요약` 으로 커밋한다.
9. 새 세션 부팅용 프롬프트를 출력한다 (harness/playbook/07_handoff.md 의 부팅 프롬프트).

## 하지 말 것
- 대화를 시간순으로 옮겨 적지 않는다. 상태와 결정만 쓴다.
- 확인되지 않은 것을 발견으로 쓰지 않는다. 열린 질문으로 쓴다.
- 한 섹션이 약 60줄을 넘지 않게 한다.
