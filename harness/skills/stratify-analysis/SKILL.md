# 층화 분석과 기여 분해

## 목적
원인 후보를 동시에 판정하고, 교란을 드러내고, 변화량을 요인별로 나눈다.

## 사용할 함수 (harness/scaffold/analysis_utils.py)
daily_trend, plot_trend, period_compare, stratify, crosstab_counts, naive_vs_stratified,
bootstrap_diff, radial_profile, plot_radial, waterfall, save_table, save_fig

## 절차
1. 시계열부터 본다. 변화가 계단형인지 점진형인지, 계단이 몇 개인지 확인하고 이벤트 날짜를 겹쳐 그린다.
2. 측정을 먼저 의심한다. 측정 조건(프로그램, 장비, 판정 기준) 변화가 있으면 그 효과를 먼저 추정·보정한다.
   보정 방법은 2개 이상 계산하고 선택은 사람에게 맡긴다.
3. 가설 요인들을 교차시킨 층화표를 만든다. 셀마다 평균, 중앙값, 단위 수를 쓰고 단위 수 10 미만은 표시한다.
   집계 단위(웨이퍼/Lot 등)를 명시하고 unit_col 로 단위 평균을 먼저 낸다.
4. 교란을 확인한다. 요인 간 교차 빈도표로 쏠림을 보고, 단순 비교와 층화 비교가 다르면 그 이유를 설명한다.
5. 독립 근거를 찾는다. 수치 비교와 다른 종류의 증거(공간 패턴, 시간 패턴, 다른 제품)로 같은 결론이 나오는지 본다.
6. 기여를 분해한다. 전체 변화 = 각 요인 기여 + 잔차. 가정(가법성 등)을 명시하고 잔차 크기를 보고한다.
7. 확신 수준을 붙인다. 주 효과에 bootstrap_diff 구간을 붙인다. 과도한 검정은 하지 않는다.

## 산출물 형식
- 결과는 outputs/tables/*.csv, outputs/figures/*.png (save_table / save_fig)
- work/FINDINGS.md 에 F-번호: 주장 / 근거 파일 / 강도(강·중·약) / 한계 / 관련 D·커밋

## 하지 말 것
- 한 가설만 단독으로 검정하지 않는다. 항상 대안 가설과 같은 표에서 비교한다.
- 상관을 인과로 단정하지 않는다. "지지한다 / 정합한다 / 반박한다" 로 쓴다.
- 물리적 메커니즘 설명을 근거 없이 길게 쓰지 않는다. 메커니즘 해석은 사람이 확정한다.
